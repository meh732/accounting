========================================================
 Persian Accounting System - Client Instructions
========================================================

The Accounting System is a web-based application. You do NOT need to install anything on the client computers!

To connect a client (any PC, mobile, or tablet in your network) to the server:

1. Make sure the server is running (you ran "start_server.bat" on the main computer).
2. Look at the output of "start_server.bat". It will show a line like:
   Client systems can access the software via: http://192.168.1.100:3000

3. Open a web browser (Google Chrome, Firefox, or Edge) on the client computer.
4. Type that address (e.g., http://192.168.1.100:3000) into the address bar and hit Enter.

That's it! You are now connected to the central accounting system.

Note:
- Ensure that the server computer's Windows Firewall allows inbound connections on port 3000.
- All data is currently stored on the client side (in the browser) for offline mode. If you want centralized data across multiple clients, you need a backend database update (Pro Version feature).
